## 📖 Sobre o projeto

O Creator Copilot é uma aplicação web que utiliza inteligência artificial para auxiliar creators iniciantes na criação de estratégias de divulgação, produção de conteúdo e organização de ações direcionadas à primeira venda.

Desenvolvido para o desafio de inovação do **Programa de Estágio YouShop 2027**, o projeto busca tornar a jornada inicial dos creators mais simples, personalizada e eficiente.

## ✨ Funcionalidades

- **Dashboard:** visão geral da jornada e recomendações personalizadas.
- **Diagnóstico:** identificação do perfil, nicho, dificuldades e objetivos do creator.
- **Plano de ação com IA:** geração de tarefas personalizadas conforme o diagnóstico.
- **Criador de conteúdo com IA:** geração de posts, roteiros e conteúdos adaptados a diferentes redes sociais.
- **Acompanhamento de progresso:** controle de tarefas e evolução individual.
- **Persistência local:** armazenamento das informações no navegador.
- **Design responsivo:** compatibilidade com computadores e dispositivos móveis.

## 🛠️ Tecnologias

- React
- TypeScript
- Tailwind CSS
- Lovable AI
- LocalStorage
- Git e GitHub

## 🎯 Objetivos

- Facilitar a jornada dos creators iniciantes.
- Aumentar a autonomia na produção de conteúdo.
- Oferecer direcionamento estratégico personalizado.
- Contribuir para a realização da primeira venda.
